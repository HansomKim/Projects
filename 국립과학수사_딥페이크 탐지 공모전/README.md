# 국립과학수사연구원 딥페이크 범죄 대응 AI 탐지모델 경진대회

이미지·동영상 속 인물 얼굴의 딥페이크 여부를 판별하는 이진 분류 모델을 개발하는 대회입니다. (진행 중)

## 과제 특징
- **입력**: 얼굴이 포함된 이미지(.png/.jpg) 또는 동영상(.mp4, 평균 5초 내외)
- **출력**: Real(0) / Fake(1) 이진 라벨
- **제출 방식**: 결과가 아닌 **모델 자체**를 제출하는 추론 자동화(inference automation) 방식
  - 비공개 테스트셋에 대해 서버에서 자동으로 추론·채점 (팀당 하루 최대 3회 제출)
- **평가지표**: Macro F1-score (Fake를 Positive 클래스로 정의)
- **데이터 특징**: 상용 생성 서비스 및 오픈소스 모델, 구형 face-swap/lip-sync 방식까지 다양한 위조 기법 포함, 인종·연령 다양성 확보
